# 拾阅移动端阅读器

专为私人 Calibre-Web 书库打造的现代化移动端 PWA 阅读器。服务端采用 Node.js (TypeScript + Express) 构建，支持 OPDS Atom 目录逐层浏览、流式封面代理、跨设备配置持久化、全文搜索以及 EPUB、PDF、TXT 沉浸式横向分页阅读。iOS 原生工程位于 `iOS/`。

## 为什么从 Python 升级为 Node.js (TypeScript)？

1. **全栈同构与类型安全**：前端交互与后端服务统一使用 TypeScript，共享 OPDS 数据结构模型与接口约定，消除了跨语言类型不一致与序列化误差。
2. **高效流式解压与电子书解析**：依托 Node.js 原生 Stream 流式管道、`fast-xml-parser` 与 `adm-zip`，在解压 EPUB 章节、解析大规模 Atom 目录和图片缓冲时具备高吞吐、低内存占用的优异表现。
3. **现代 Web 生态支持**：开箱即用支持 PWA Service Worker 离线网络策略、静态资源零配置缓存控制、Cookie 会话加固及 `npm run dev` / `npm start` 极速启动。

## 本地运行与部署

### 1. 本地开发

直接双击 `index.html`（`file://`）会被浏览器安全策略阻止调用 OPDS 代理与封面接口。在项目根目录下运行：

```sh
npm install
npm run dev
```

浏览器打开 `http://localhost:3000` 即可使用。

### 2. Docker 部署

首次部署时复制 `.env.example` 为 `.env`，设置应用访问密码 `APP_PASSWORD`：

```sh
docker compose up -d --build
```

- `config/calibre-web.json`：持久化保存 Calibre-Web OPDS 凭据与地址（容器重启后保留）。
- `config/bookshelf.json`：持久化保存“我的书架”收藏。
- `config/history.json`：持久化保存阅读与浏览历史。

## 核心功能矩阵

- **四大核心视图**：
  - **书店**：实时解析 Calibre-Web OPDS 目录，支持最新上架、分类探索、按作者搜索与逐级返回导航。
  - **书架**：私人藏书阁，一键从书店加入/移出书架，支持本地与服务器双向同步。
  - **首页**：最近阅读进度恢复、正在读卡片展示、随机挑选好书推荐。
  - **我（个人中心）**：读书排行榜（按阅读时长精准统计）、在读/读完状态标记与年份归档、**读书笔记与书签专区**、浏览足迹与书库管理。
- **全能排版阅读器**：
  - **多主题切换**：护眼米黄、羊皮纸复古暖色、白纸纯净模式、夜间深色模式。
  - **字体与版式定制**：支持宋体 (Noto Serif SC)、现代黑体 (Sans-serif)、古典楷体 (Kaiti)，以及紧凑、适中、宽松三档行间距调节。
  - **读书笔记与批注**：阅读器内可一键写下心得与段落思考，记录精准至具体书籍和页码，支持在个人中心随时温习回顾并一键跳转回对应页面。
  - **进度与翻页**：自适应横向分页、触控滑动、左右按键/屏幕边缘点击翻页、全屏沉浸阅读模式（⛶）、进度自动实时记录。
  - **多格式支持**：EPUB 章节流式加载解析、TXT 智能分段分页排版、PDF 内置查看器。
